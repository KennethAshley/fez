# ECC pattern learning: inspection and fit for Fez

Reviewed 2026-09-12 at ECC commit [`c4904e3f6381df934fc00bffb0afa7a1f8dae0e3`](https://github.com/affaan-m/ECC/tree/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3). Scope: continuous-learning-v2, its Claude capture/observer pipeline, SessionStart application, evolution/promotion CLI, and the corresponding existing Fez memory and skill paths. This is source inspection plus isolated offline checks. No ECC installation, real model calls, or Fez runtime changes were made. Other harness adapters were not verified for parity.

## Decision

Borrow the small, scoped lesson format. Do not treat ECC's confidence or skill generation as evidence that the agent has improved. The pipeline really can turn tool activity into instructions used in later sessions, but correctness is largely delegated to the same model that proposes the instructions.

The strongest reproduced limitation: two contradictory instincts, each at **20% confidence**, were combined into a generated skill containing both actions. This was a draft-file generation test; it did not automatically activate that skill.

Fez already has encrypted private memory, signed shared memory with corrections, automatic instructions to remember durable facts, and progressive skill loading. Any useful addition should reuse those paths. The inspected Fez paths did not reveal an equivalent automatic observer-to-skill promotion process; that is narrower than saying Fez lacks learning or memory.

## How the implemented loop works

1. **Capture tool activity.** Pre/post-tool hooks record selected tool metadata and input/output into project-scoped JSONL. Project identity derives from a Git remote or repository path. Capture runs for eligible sessions in standard/strict hook profiles; minimal, excluded, subagent, unknown-entrypoint, and observer sessions are skipped. [Hook registration](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/hooks/hooks.json#L50), [post-tool dispatcher](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/scripts/hooks/posttooluse-dispatcher.js#L36), [guards](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/skills/continuous-learning-v2/hooks/observe.sh#L140).
2. **Optionally analyze observations.** The observer defaults disabled, although eligible observations are already recorded before that setting is checked. When enabled, defaults are a five-minute interval, at least 20 records, and the configured Claude `haiku` model. [Config](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/skills/continuous-learning-v2/config.json#L1), [capture before observer enable check](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/skills/continuous-learning-v2/hooks/observe.sh#L356).
3. **Write an “instinct.”** An LLM reads sampled observations and directly writes Markdown with frontmatter: an ID, trigger, confidence, domain, scope, action, and free-text evidence. The executed prompt asks for patterns seen at least three times. An instinct is a small saved instruction; this is prompt/context adaptation, not model-weight training. [Executed prompt](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/skills/continuous-learning-v2/agents/observer-loop.sh#L268).
4. **Reuse selected instructions.** SessionStart reads project and global personal/inherited instincts. Defaults admit confidence ≥0.7 and select at most six, ranked by confidence plus project/stack relevance. The hook emits them as session context. Project versions win ID collisions. [Selection and injection](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/scripts/hooks/session-start.js#L411), [context output](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/scripts/hooks/session-start.js#L644).
5. **Optionally evolve or promote.** Invoked CLI commands cluster instincts into skill drafts, wrap workflow instincts as commands, or promote project instincts to global scope. These are distinct from the running observer and from normal instinct injection. [Evolution](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/skills/continuous-learning-v2/scripts/instinct-cli.py#L1305), [promotion](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/skills/continuous-learning-v2/scripts/instinct-cli.py#L1661).

## What “learning” and confidence actually mean

The executed observer prompt assigns confidence by recurrence: 3–5 observations → 0.5; 6–10 → 0.7; 11+ → 0.85. Counts and evidence are authored by the model, not independently calculated or linked to required source-record IDs. Repeated behavior can be a convention, but repetition alone does not establish that it succeeds. [Actual confidence instructions](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/skills/continuous-learning-v2/agents/observer-loop.sh#L268).

The separate observer guidance describes confirmation increases, contradiction penalties, and weekly decay. The running shell loop builds its own prompt rather than loading that document, and those adjustment rules were not found implemented in the reviewed learning path. Treat them as guidance, not guaranteed bookkeeping. [Separate guidance](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/skills/continuous-learning-v2/agents/observer.md#L128), [generated prompt](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/skills/continuous-learning-v2/agents/observer-loop.sh#L268).

The captured evidence is also narrower than “learn from corrections and outcomes” suggests. Normal records contain tool metadata and I/O, truncated to 5,000 characters per field. They do not directly record user messages, an explicit success flag, or the parsed `tool_use_id`. A correction or outcome is available only to the extent it can be inferred from the sampled tool activity. [Parsed fields](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/skills/continuous-learning-v2/hooks/observe.sh#L226), [persisted fields](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/skills/continuous-learning-v2/hooks/observe.sh#L329).

## Operational safeguards and limits

The observer has useful process safeguards: a 120-second default timeout, child-process termination, retry on failed/incomplete analysis, an explicit untrusted-observation prompt, and an isolated completion result. Successful CLI exit plus an exact final completion marker allows archival. These checks establish execution completion, not evidence accuracy, valid instinct schema, or improved behavior. Instincts written before a later failure are not rolled back. [Prompt boundary](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/skills/continuous-learning-v2/agents/observer-loop.sh#L298), [watchdog and completion](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/skills/continuous-learning-v2/agents/observer-loop.sh#L369).

Analysis samples the latest 500 records but success archives the entire live observations file. Older unsampled records and records appended during inference can therefore leave the pending queue without analysis; they remain archived. The capture cleanup purges `observations-*.jsonl` older than 30 days, while completed analyses use `processed-*.jsonl`, so that cleanup does not cover completed archives. [Sampling](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/skills/continuous-learning-v2/agents/observer-loop.sh#L226), [archive](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/skills/continuous-learning-v2/agents/observer-loop.sh#L463), [purge](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/skills/continuous-learning-v2/hooks/observe.sh#L200).

Observations are locally stored, but enabled inference sends their contents through the configured Claude model service. The regex scrubber covers selected named credentials, not all code, personal information, or secrets. The observer preapproves `Read,Write`; these flags are not an independent filesystem sandbox. No monetary budget was found in the reviewed invocation, although turn and timeout limits exist. [Scrubber](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/skills/continuous-learning-v2/hooks/observe.sh#L339), [turn limits](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/skills/continuous-learning-v2/agents/observer-loop.sh#L330), [model invocation](https://github.com/affaan-m/ECC/blob/c4904e3f6381df934fc00bffb0afa7a1f8dae0e3/skills/continuous-learning-v2/agents/observer-loop.sh#L398).

## What Fez already provides

| Need | Existing implementation |
| --- | --- |
| Private persistent lessons | Agent-signed kind-30174 engrams, NIP-44 encrypted between agent and owner, with topic records and core memory. [engram.ts](/Users/ken/Projects/Fez/fez/src/agent/engram.ts:11) |
| Remembering without an explicit save request | The runtime already tells agents to save durable preferences, decisions, and standing context to `mem/<topic>` without being asked, and report that they did. [memory-prompt.ts](/Users/ken/Projects/Fez/fez/packages/fez-acp/src/memory-prompt.ts:42) |
| Shared knowledge and correction | Signed shared memory kind 47210, authorized correction/forgetting kind 47211, and current-state recall. [fez-memory README](/Users/ken/Projects/Fez/fez/packages/fez-memory/README.md:7) |
| Reusable procedures | Attached skill name/description menu, bodies loaded through `fez_load_skill`, and authenticated owner input for manual skills. [skills-prompt.ts](/Users/ken/Projects/Fez/fez/packages/fez-acp/src/skills-prompt.ts:11) |

The smallest useful adaptation would save a **candidate lesson** through existing memory after a concrete correction or verified result: when it applies, what to do, and the source task/event that supports it. Preserve the trigger whenever it is recalled. Existing correction/forgetting paths should handle changed lessons. A reusable skill should be attached only after owner review or an appropriate behavioral check, rather than treating recurrence as proof. This is a recommendation, not implemented behavior or a launch prerequisite.

Do not fold a lesson's self-assigned confidence into Salt, stake, or backing. Those describe different evidence about an actor; an instruction still needs evidence that it is appropriate for its task.
