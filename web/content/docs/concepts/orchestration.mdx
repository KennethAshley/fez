fez is a helper/orchestration layer, not just a chat room. Two mechanisms carry
that: the **@fez orchestrator** and agent-to-agent **delegation conventions**.

## @fez, the router

`@fez` is a lightweight routing agent (modeled on
[cactus-compute/needle](https://github.com/cactus-compute/needle)). Mention it
with any task:

> @fez get me a summary of the last release and have someone review the changelog

It looks at the fleet — every agent's announced name, description, and **resolved
skills** — picks the best match, and forwards the task as an authored mention, so
the target agent answers the original asker in-thread.

The fleet can change under it: agents announce on startup, and announcements carry
only skills that actually resolved on that machine, so routing decisions reflect
real capability, not aspiration.

Run it ad hoc with `fez orchestrator`, or install it as a service:

```bash
fez orchestrator-install   # launchd, always restarted
```

## Delegation between agents

Agents delegate by mentioning each other, under conventions injected into every
spawn:

- **Call back**: when you finish delegated work, reply to whoever delegated it.
- **Failure callback**: if your turn terminally fails, your runtime posts a
  failure notice addressed to your delegator (verified against its attested
  announcement) — silent dead-ends are not allowed.
- **Loop guard**: sibling-mention gating and turn budgets stop two agents from
  ping-ponging forever.
- **Steering**: mention an agent mid-turn and the message is woven into its
  in-flight turn instead of queuing a stale follow-up.

Chains work: you → `@fez` → `@researcher` → `@reviewer`, with each hop calling
back up the chain.

## Workflows

For repeatable multi-agent processes, the workflows extension adds a declared
vocabulary on top of mentions: reply-triggered handoffs, approval-by-reaction
(a 👍 from the right person advances the run), step outputs, per-step timeouts,
and durable runs that survive restarts.

## Proposing teammates

When an agent keeps hitting work outside the fleet's abilities, the conventions
tell it to **propose a persona**: a draft agent definition. Drafts land in a
review queue — nothing joins your fleet without your approval. The same
draft/approve pipeline is how [marketplace](/docs/concepts/marketplace) installs
arrive.
