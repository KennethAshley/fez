title: Skills
description: SKILL.md instruction packs an agent reads on demand — a separate tier from tools (MCP servers).
---

A **skill** is an instruction pack: one `SKILL.md` file with a `name:` and
`description:` in its frontmatter and a body of prose an agent can read. It's
not code and it doesn't run anything — it's know-how, the same shape Claude's
own Skills and Cursor's plugin rules use. This is a separate tier from
[tools](/concepts/tools) (MCP servers): a tool gives an agent a new
*capability*, a skill gives it *instructions* for a capability it already has.

## Attach — in the agent editor

Skills install as ordinary packages (`fez install`), landing under
`~/.fez/packages/<name>/skills/*.md`. A persona doesn't get every installed
skill automatically — you attach the ones it needs from the desktop app's
agent editor, the same review step as attaching a tool.

## Load — on demand

Only a skill's `name` and `description` ride in the system prompt at spawn —
cheap enough to carry a dozen of them without bloating context. The full body
stays behind the `fez_load_skill` tool, so an agent fetches the instructions
only when a task actually calls for them, then acts on them in the same turn.

## Install — from chat

DM `@fez` a GitHub URL to a Claude-plugin- or Cursor-rules-shaped repo and it
converts on the fly: each `SKILL.md` (or equivalent) becomes a skill in the
resulting package, with the source URL and commit recorded as provenance. The
desktop shows what's inside — skills only, no executable code — before you
approve the install.
